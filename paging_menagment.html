Page Replacement Algorithms Simulation

Optimal, LRU, FIFO, NFU, Second Chance and Clock Replacement.

Optimal (OPT)

Replaces the page that will not be used for the longest time in the future.

LRU

Least Recently Used — evicts the page that was requested least recently.

FIFO

First-In First-Out — replaces the page that has been in memory the longest.

NFU

Not Frequently Used — evicts the page with the lowest access counter.

Second Chance

FIFO modification inspecting the reference bit before replacement.

Clock Replacement

Circular list implementation of Second Chance with a moving clock hand.
